How It Works

STEP 01

Upload

Browser to Flask API

You pick a CT slice and the page sends it to the /predict endpoint as base64. The server decodes it in memory, so nothing is written to disk.

sample-scan.jpguploading…

STEP 02

Preprocess

Resize to 224 × 224

The image is resized to the network's 224 × 224 input with bilinear interpolation, then run through VGG16's ImageNet preprocessing. Training, evaluation and prediction all share this one step.

→

Any size in, 224 × 224 out

STEP 03

Classify

VGG16 transfer learning

A VGG16 backbone pretrained on ImageNet turns the scan into features. Its layers stay frozen, and a small softmax head trained on the Kaggle CT Kidney dataset scores each class.

64 128 256 512 512
→
NormalTumor

5 frozen conv blocks, then a softmax head

STEP 04

Track

DVC pipeline + MLflow

Each stage, from data ingestion to evaluation, is a reproducible DVC stage. Evaluation writes the test-set metrics to scores.json, which feeds the model report below, and the same run can be logged to MLflow.
